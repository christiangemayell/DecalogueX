# DecalogueX: Crash Doctor

**Finds and fixes the security and crash mistakes AI coding tools leave behind.**

```
npx decaloguex scan .
```

It checks JavaScript, TypeScript, Python, PHP, Java, C#, Go, Ruby, Kotlin,
Swift, HTML, Vue and Svelte. It explains every problem in plain words, and
fixes the ones you say yes to: leaked passwords and API keys, SQL injection,
error messages that leak private details, and code that can crash your server.

Changed your mind? `npx decaloguex undo` puts everything back.

DecalogueX is written in Python. This package finds Python on your computer
and runs it for you (installing DecalogueX the first time). You need
Python 3.10 or newer: https://www.python.org/downloads/

Full guide: https://github.com/christiangemayell/decaloguex
